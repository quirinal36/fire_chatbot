## 1. 수집 완전성과 버전

- 선정 목록: 법령 6종, NFPC·NFTC 20종, 소방청 해석 2건 (`server/src/lib/ingestion/catalog.ts`)
- 수집 결과: 29개 버전(시행령 2027-01-01 시행예정 버전 포함). 조문·부칙·필수 별표(시행령 2·4·5·7, 다중이용업소법 시행령 1)의 누락은 0건이다
- 오류 구별: HTTP 200으로 오는 인증 오류, HTML 오류, 빈 본문, `resultCode` 이상은 성공으로 처리하지 않는다 (`client.test.ts`, `adapters.test.ts`)
- 혼용 없음: 오늘 기준 검색 대상에 시행예정 버전이 0건이다. 기준일을 2027-01-02로 주면 시행예정 버전이 검색된다 (`versions_as_of`)
- 재조회: 근거 카드는 답변에 저장된 단위 id로 해당 버전 원문을 돌려준다. 현행이 아니면 현행 조문으로 가는 링크를 붙인다
- 재실행: `cd server && npm run ingest` (변경이 없으면 29건 모두 unchanged)

## 4. 인용과 답변 충돌

부하 시험 100건 (`node scripts/load-test.mjs`):

- 답변에 인용한 근거 190건을 모두 `GET /api/sources/:id`로 조회했고, 실패는 0건이다
- 답변의 근거 목록에 없는 인용 id는 0건이다
- 모델이 URL을 만들지 않는다. 링크는 DB의 공식 주소만 쓴다

**규칙 결과와 다른 결론** — 검증 단계에서 막는다 (`conflictsWithAssessment`, `validateAnswer`).

1. 영업장 사례가 있는 질문에서 모델이 확인 전 수치로 "소화기구를 설치해야 합니다"라고 단정했다. 규칙 결과는 "추가 확인"이었다. → 충돌 검증과 프롬프트 지침을 추가했고, 이후 충돌 0건이다.
2. 운영 재시험에서 "학원 계단에는 유도표지를 설치하지 않아도 됩니다"라는 답변이 나왔다. 기술기준의 제외 조건(유도등이 적합하게 설치된 계단)을 뺀 부정확한 단정이다. 앞서 검사 범위를 좁히면서 놓친 것이었다. → 학원을 주어로 한 단정을 다시 검사 대상에 넣었다.
3. 사례 질문 답변에 "자동화재탐지설비 판정 시 강의실 바닥면적을 1.9㎡로 나눈다"는 문장이 있었다. 1.9㎡는 수용인원 산정 기준이다. **형식 검증으로는 잡을 수 없는 의미 오류다.** 이런 오류는 담당자 검수와 오류 신고로 잡아야 한다.

**판정: 조건부 충족.** 규칙과 정면으로 충돌하는 결론은 차단한다. 그러나 조건을 빠뜨린 요약이나 근거를 잘못 연결한 설명은 남을 수 있다. 담당자 검수 사례로 다시 확인해야 한다.

## 8. 핵심 E2E

`aside repl` 은 한 번에 120초까지 돌고 자기 세션 폴더 밖에 파일을 쓰지 못하므로, 흐름 하나를 그 안에 끝내고 실행기가 스크린샷을 `e2e/out/`으로 옮긴다.

| 화면 확대·복귀 시 상태 복원 | `도면 크게 보기` → 대화 감춤·캔버스 405→1406px·면적 유지, `이전 화면으로` → 대화 복원·캔버스 405px·면적 유지 | 충족 |

평면에서 벽이 원본을 가리지 않는 것은 화면 갈무리로 확인했다. 평면에서는 벽 높이만 2cm 로 눌러 원본 도면과 구역 색·이름이 모두 보이고, 3D 에서는 벽이 다시 선다.

## 11. 단계 안내와 AI 호출 (UX-003)

2026-09-19, 같은 환경에서 확인했다. 도면 탭을 열고 `길이를 몰라요 → 인식 결과 확인 → 벽 고치기` 순으로 누르며 단계 표시와 면적을 쟀다. AI 호출은 `window.fetch` 를 감싸 `/api/plans/*` 요청을 세었다.

| 완료 조건 | 측정 | 판정 |
|---|---|---|
| 출처·현재 단계·다음 행동을 화면에서 확인 | `예시 도면 · default.png` 와 4단계 목록, `지금 할 일 · 면적을 맞추려면 실제 길이가 필요합니다` + 주 버튼 1개 | 충족 |
| 탭·패널 전환에도 도면·편집 보존 | 벽을 고쳐 `87.2㎡` 로 만든 뒤 근거 법령 → 내 영업장 → 패널 닫기 → 다시 도면: `87.2㎡` 그대로 | 충족 |
| 바뀐 뒤 옛 확인이 남지 않음 | 확인 후 벽 추가 → 3단계가 `도면이 바뀜 · 인식 결과 다시 확인` 으로 되돌아감 | 충족 |

`예시 도면` 은 이전에 자동 치수 읽기를 함께 불렀다. 체험이 유료 호출과 하루 한도를 쓰는 것은 맞지 않아 사용자가 `도면의 치수 자동 읽기` 를 누를 때만 부르도록 바꿨다.
