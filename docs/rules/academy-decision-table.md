# 교육서비스 학원 소방시설 설치 대상 판단표

규칙 버전 `academy@2026-09-18.1` · 이 문서는 `npm run rules -- table` 로 생성한다. 직접 고치지 않는다.

적용 범위: 일반 학원(자동차운전·정비학원, 무도학원 제외). 근린생활시설 또는 교육연구시설로 분류되는 경우

> **담당자 승인 전 초안이다.** 승인 전에는 운영 화면에 판정을 내보내지 않는다. 승인 절차는 아래 "승인 기록" 참고.

## 담당자 검토 요청 사항

1. **렛츠코딩앤플레이의 "연면적 112㎡"가 건물 전체 연면적인지 학원 영업장 면적인지** 확인. 현재는 영업장 면적으로만 쓴다.
2. 피난기구: 3층 영업장이 피난층이 아니라는 확인이 필요하다 (A01 에서 추가 확인으로 둠).
3. 옥내소화전·비상경보·자동화재탐지는 건물 전체 연면적 기준이다. 건축물대장 수치로 확정한다.
4. 다중이용업: 수용인원 25명은 사용자가 말한 값이다. 별표 7(강의실 등 바닥면적 ÷ 1.9㎡) 산정값과 일치하는지 확인.
5. 부칙 경과조치(건축허가일 기준 구 기준 적용)는 규칙에 넣지 않았다. 허가일이 오래된 건물은 담당자 판단으로 남긴다.
6. 복합건축물(주택과 함께 쓰는 건물), 노유자 시설 예외 등 학원과 무관한 조항은 범위 밖이다.
