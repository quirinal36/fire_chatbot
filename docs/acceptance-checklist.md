# 최종 검수 체크리스트 (ISS-032)

대상 독자: 최종 검수를 수행하는 소방 업무 담당자와 의뢰자.

운영 환경에서 담당자가 직접 확인한다. 각 항목에 결과·증거·검토자·일자를 적는다. 개발자 자체 검수 결과는 [검수 보고서](verification-report.md)에 있다.

## 사전 조건

- [ ] 판단표 승인 ([decisions.md](decisions.md) D1) — `docs/rules/academy-decision-table.md`
- [ ] 검색 평가셋 정답 확인 (D2) — `evals/search/questions.jsonl`의 `review`를 `approved`로 바꾸고 재측정
- [ ] 외부 전송 운영 승인 (D3)
- [ ] 운영 계정·도메인·요금제 (D5·D7·D8)
- [ ] 운영 배포 점검 (ISS-030)
